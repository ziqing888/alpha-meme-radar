# JEV + Claude MEME 平台候选工具（用户提供线索）

## 记录性质

本页用于保存用户提供的候选项目、宣传能力与后续研究方向。星标数、用户数、延迟、手续费优惠、链支持和订单能力均为用户提供的时点信息，尚未完成源码、官方文档或运行验证，不应直接作为接入或实盘依据。

## 候选工具

### 1. jev-trader

- 来源：<https://github.com/jarrodwatts/jev-trader>
- 用户提供信息：约 2.6k stars。
- 定位：Monad 上按区块运行的 JEV 买卖决策模板。
- 宣传能力：约每 300ms 决策一次；添加钱包前使用真实订单簿进行模拟；适合作为低延迟模板修改。
- 预期研究价值：事件循环、模拟/实盘切换边界、区块级候选决策接口。

### 2. quantdinger

- 来源：<https://github.com/OpenByteInc/QuantDinger>
- 用户提供信息：约 12.3k stars。
- 定位：交易请求前置 JEV 审批闸门。
- 宣传能力：被拒交易不进入交易所；退出和止损路径绕过 AI。
- 预期研究价值：开仓前拒绝闸门、确定性退出、故障时仓位保护、AI 与执行层隔离。

### 3. gmgn-skills

- 来源：<https://github.com/GMGNAI/gmgn-skills>
- 用户提供信息：约 587 stars。
- 定位：向 Claude 提供 MEME 数据与交易能力。
- 宣传能力：机构资金、KOL、内部人士、聚合钱包；约 0.3 秒发单；止盈止损；支持 Solana、BSC、Base 等链。
- 当前本地关系：现有 MEME 雷达已经使用 GMGN 数据适配层；任何新增执行能力仍需独立评估，不能因数据接入而自动获得实盘权限。

### 4. copyfomo

- 来源：<https://t.me/copyfomo_bot>
- 用户提供信息：70K+ 用户、手续费优惠 10%。
- 定位：复制 FOMO 交易者买卖动作的外部执行机器人。
- 宣传能力：按用户交易量在数秒内复制；最多三个止盈点和一个止损点；支持 Robinhood Chain、Solana、Base、BNB 等。
- 预期研究价值：跟单事件模型、多段止盈、止损与跨链执行接口。
- 边界：外部机器人不能直接成为精选、仓位或实盘事实来源；接入前需核验可审计回执、失败语义、幂等性和退出控制。

### 5. memecoin-claude

- 来源：<https://github.com/seelffff/memecoin-claude>
- 定位：面向 Claude 的反证优先 `CLAUDE.md`。
- 宣传能力：先寻找不应买入的理由，要求证据优先，并计算退出流动性后再决定是否拒绝跟进。
- 预期研究价值：负面证据闸门、退出流动性、拒绝优先的候选审核模板。

## 后续构建边界

1. 先做只读源码与接口审计，再决定是否吸收设计；不以宣传指标代替验证。
2. 监控、影子判断、模拟交易和实盘执行必须是独立层。
3. JEV 只复核已收集的候选与证据，不作为行情源，也不能凭判断补全缺失事实。
4. 新开仓可经过 JEV/Claude 拒绝闸门；止损、强制退出和风险熔断保持确定性，不依赖模型在线。
5. ARC 继续保持监控专用；未经单独确认，不加入 ARC 钱包、路由、订单或仓位流程。
6. `精选总览` 继续只显示 `aggregate_early_bird` 与 `aggregate_confirmation`；发现层不直接进入精选。
7. 任何外部交易机器人或钱包接入均作为独立后续工作，不在本资料归档步骤中启用。
